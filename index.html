PROJECT WALKTHROUGH

Financial Data ETL Pipeline for RAG

A local Python ETL pipeline that turns public market data and SEC regulatory filings into a RAG-ready gold layer — one clean, retrievable document per company.

Yahoo Finance API SEC EDGAR API Pandas Python
01 — EXTRACT
SOURCE A

Stock price history

Pulled via the Yahoo Finance API (yfinance) — one year of daily prices plus company metadata (sector, market cap) per ticker.

SOURCE B

SEC regulatory filings

Pulled via the SEC EDGAR Company Facts API — real filed figures (revenue, net income, assets), deeply nested across every historical filing.

↓
02 — CLEAN & TRANSFORM
CLEAN A

Derive price metrics

Raw daily rows collapse into summary metrics: latest close, 52-week high/low, and 1-year percent change.

CLEAN B

Filter to annual filings

SEC JSON is filtered down to 10-K annual figures only, keeping the most recently filed value per tag and handling missing tags gracefully.

↓
03 — JOIN & FLATTEN
MERGE

One unified record per company

Price metrics, SEC fundamentals, and company metadata are joined by ticker into a single structured record per company.

GOLD LAYER

Flattened into natural-language documents

Each joined record is rewritten as a short paragraph — the format a retrieval system can actually search semantically. This is the key difference from a traditional BI gold layer: retrievable text, not normalized tables.

↓
04 — SERVE
CONSUMED BY

RAG chatbot

The generated .txt documents feed directly into the chunking → embedding → retrieval pipeline of the companion RAG chatbot project, answering natural-language questions about company financials.
